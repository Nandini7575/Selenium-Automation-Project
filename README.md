# Selenium Automation Testing Project

## 📌 Project Overview
This project is built using Selenium WebDriver with Java to automate a demo web application.

## 🌐 Application Under Test
https://iamsandesh23.github.io/selenium.github.io/

## 🧪 Test Scenarios Covered
- Website URL validation
- Page title validation
- Login functionality (Username & Password)
- Radio button selection
- Checkbox selection
- Button click validation
- Alert handling
- Text validation on page

## 🛠 Tools & Technologies Used
- Selenium WebDriver
- Java
- ChromeDriver
- Eclipse IDE

## 📂 Project File
- DemoSiteTest.java

## ▶️ How to Run
1. Open project in Eclipse
2. Ensure Selenium dependencies are added
3. Run `DemoSiteTest.java` as Java Application

## 📌 Key Learning
- Element locating strategies (XPath, tagName)
- Handling alerts
- Basic automation flow
- Validation using Selenium
